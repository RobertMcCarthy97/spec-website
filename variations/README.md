# Design variations (record only)

The live design is the root `index.html`. Everything in this folder is a historical
snapshot from the 2026-10-06 design session and is not maintained.

- `v1/` – first redesign as pushed (Public Sans + Source Serif, warm paper, teal links)
- `v2/`, `v3/`, `v4/` – type and colour directions: standards body, journal, technical spec. v2 was chosen.
- `cues/` – eight single-cue pages hinting that the framed page is a specification. Only the
  "definition brand" long name was kept, and later restyled.
- `fonts/` – body and heading pairings. STIX Two Text throughout (f6) was chosen; `compare.html`
  shows two side by side.
- `frame/` – frame treatments. The Oxford rule (a) was chosen; d and e (header variants) were rejected.

Photo paths in these pages point at `../../assets/people/` or `../../../assets/people/`, so they
only render when served from the repo root.
